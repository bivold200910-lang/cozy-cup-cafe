Welcome to Cozy Cup Cafe! A funky, retro-inspired café website built as my project for Hack Club's Boba Bash.

**Code. Sip. Repeat.**

## About the Project

Cozy Cup Cafe is a fictional café website inspired by nostalgic internet aesthetics, warm coffee-shop vibes, and colourful decorations.

I wanted to create something playful rather than a typical minimalist website.

## Built With

- HTML5
- CSS3

No JavaScript was used in this project.

## Features

- Retro-inspired café design
- Decorative GIFs and images
- Interactive navigation menu
- Separate Dev Notes page
- Custom typography and colour combinations
- Café menu featuring drinks and snacks

## What I Learned

This project helped me practise HTML and CSS while learning about:

- Positioning elements on a webpage
- Working with background images
- Using custom fonts and colours
- Creating navigation links
- Organising website files
- Debugging layout and styling issues

One of my biggest challenges was finding colour combinations that matched the overall aesthetic while keeping the text readable.
